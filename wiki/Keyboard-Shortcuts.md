# Keyboard Shortcuts

## Global navigation

| Shortcut | Action |
| --- | --- |
| `/` | Open note search (while not typing in an input field) |
| `Ctrl+Alt+N` / `Cmd+Option+N` | Create a new note |
| `Ctrl+Alt+H` / `Cmd+Option+H` | Go to the home page |

These private navigation shortcuts do not operate on public note pages or the login screen.

## Viewing an authenticated note

| Shortcut | Action |
| --- | --- |
| `e` | Switch to edit mode when editing is enabled |

## Editing a note

| Shortcut | Action |
| --- | --- |
| `Ctrl+Enter` / `Cmd+Enter` | Save |
| `Esc` | Exit edit mode (prompt if changes are unsaved) |
| `Ctrl+B` / `Cmd+B` | Bold |
| `Ctrl+I` / `Cmd+I` | Italic |
| `Ctrl+S` | Strikethrough (editor behavior) |

On an anonymously editable shared note, use `Ctrl+Enter` / `Cmd+Enter` to save content changes. The public editor cannot rename, delete, or publish notes.

See [Publishing Notes](https://github.com/erathaowl/flatnotes/wiki/Publishing-Notes).
